# Personal Ring Archive

Personal export and analysis of the owner's ring data.

## About this project

Personal Ring Archive is a private, non-commercial project operated by one individual to work with their own Oura account data. It is intended to retrieve selected records through the Oura API, organize them, and save them in a private GitHub repository for personal review and analysis.

The project does not offer account registration, collect other people's ring data, or provide a public data service. This public repository contains project documentation only. Health records, exported files, credentials, and the private repository address are not published here.

## Planned operation

The owner authorizes access through Oura. A script running in GitHub Actions retrieves the selected data on a schedule and writes the results to the owner's private repository. Access permissions and the export configuration determine which records are retrieved.

The integration is being configured. The project scope and conditions are described in the Terms of Service below.
